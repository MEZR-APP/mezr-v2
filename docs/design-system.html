09 / KEY INSIGHTS

Breathing circles are animated (mainAnim scale, pulseAnim) // - Breath Module: Active scale animation // - Meditate Module: Subtle breathing pulse (1 → 1.05 → 1) // // 2. Module has specific button flows: // - Breath: PAUSE, SKIP, RESET (when active) // - Swim: Tap-to-count (no button flow) // - Meditate: Timer with auto-complete // - Gaze: START → PAUSE/RESUME → END // // 3. Bottom tab bar is 64px with 28px additional bottom padding // This prevents content from being hidden behind it // // 4. All typography uses letter-spacing extensively: // - Headings: 4px-8px tracking // - Labels: 2px-4px tracking // - Small text: 1px-2px tracking // // 5. Colors are strictly minimal: // - Dark theme (#000, #0a0a0a, #111, #1a1a1a) // - White text (#fff) // - Grey accents (#333-#888) // - Single alert color (#ff4444) // // 6. All borders use 1px-1.5px width in #222 or #333 // // 7. Border radius follows pattern: // - Circles: 50% // - Buttons: 25px (small) → 40px (large) // - Cards: 8px
